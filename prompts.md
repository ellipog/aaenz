# Aaen — image prompt sheet

Kept from the previous mockup. Paste one block at a time into Nano Banana Pro or any image model. Set the aspect ratio in the model UI (it is named in each heading). Every block contains the same Evangelion style spine word for word — do not paraphrase it, or the set drifts.

## House rules (READ FIRST)

```text
Read this once, then paste one block at a time into Nano Banana Pro or any image model. Every block contains the same style spine, word for word — do not paraphrase it, or the set drifts between images. Set the aspect ratio in the model's UI; each prompt also names it. For maximum consistency: keep the same model version and, where possible, the same seed across a whole batch, and generate the full set in one sitting. If a result comes back with a border, a frame, a white margin, text, or colour where none is allowed, re-run the same prompt and append: "No border, no frame, no margin, no vignette, no text, no letters, no signature, no logo, no watermark." The direction is Neon Genesis Evangelion — the 1995 TV series' art direction, framing and ink quality — but never its characters: no recognisable faces, no named pilots, no copied EVA unit, only the visual language of scale, fog, geometry, wings, crosses and monoliths. The three emblem blocks are deliberately flat: solid shapes on a pure white field, no paper texture, no grain, no ink bleed, so they trace cleanly to vector and can be rebuilt on the logo grid.
```
